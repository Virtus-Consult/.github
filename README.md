# .github — Virtus

Repositório especial da organização **Virtus**. Os arquivos aqui são aplicados **automaticamente a todos os repositórios** da org que não tiverem sua própria versão.

## O que existe aqui

| Caminho | Função |
| --- | --- |
| `profile/README.md` | Página pública da organização (github.com/Virtus-Consult) |
| `CODE_OF_CONDUCT.md` | Código de conduta padrão |
| `CONTRIBUTING.md` | Guia de contribuição padrão |
| `SECURITY.md` | Política de segurança e reporte de vulnerabilidades |
| `SUPPORT.md` | Canais de suporte |
| `GOVERNANCE.md` | Papéis, times e tomada de decisão |
| `ISSUE_TEMPLATE/` | Formulários de issue padrão (bug, feature, tarefa) |
| `PULL_REQUEST_TEMPLATE.md` | Template padrão de PR |
| `workflow-templates/` | Workflows de CI sugeridos na aba **Actions** de cada repo |
| `labels.yml` | Conjunto padrão de labels da org |
| `rulesets/` | Rulesets da org (proteção da `main`) prontos para importar |
| `scripts/` | Scripts para aplicar configurações da org via `gh` CLI |
| `docs/` | Padrões de engenharia (branches, commits, nomes, releases) |

## Como alterar um padrão

1. Abra uma issue descrevendo a mudança.
2. Abra um PR — mudanças aqui afetam **todos** os repos, por isso exigem aprovação de `@Virtus-Consult/admins`.
