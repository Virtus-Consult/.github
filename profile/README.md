## 🛠️ Como trabalhamos

- **Trunk-based** com branches curtas e Pull Requests revisados
- **Conventional Commits** e versionamento semântico
- **CI obrigatório** antes de qualquer merge na `main`
- **Segurança por padrão**: Dependabot, secret scanning e 2FA para todos os membros
