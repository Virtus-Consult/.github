# Suporte

| Precisa de... | Use |
| --- | --- |
| Reportar um bug | Issue com o template **Bug** no repositório afetado |
| Sugerir uma funcionalidade | Issue com o template **Funcionalidade** |
| Tirar uma dúvida | [GitHub Discussions](https://github.com/orgs/Virtus-Consult/discussions) |
| Reportar falha de segurança | Veja [SECURITY.md](SECURITY.md) — **nunca** em issue pública |
| Falar com os admins | Mencione `@Virtus-Consult/admins` |

Antes de abrir uma issue, procure se já existe uma semelhante.
